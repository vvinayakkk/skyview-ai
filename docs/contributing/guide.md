# 🤝 Contributing to SkyView AG-RIN

Thank you for your interest in contributing to SkyView! Whether you are writing firmware for agricultural sensors, improving AI model consensus, optimizing the web UI, or expanding multilingual support in Flutter, your contributions are welcome.

---

## 🌟 Code of Conduct

We are committed to providing a friendly, safe, and welcoming environment for all contributors regardless of background, gender, or technical experience. Please treat everyone with respect and empathy.

---

## 🚀 Quick Contribution Flow

```mermaid
flowchart LR
    Fork[1. Fork / Clone Repo] --> Branch[2. Create Feature Branch]
    Branch --> Code[3. Code & Test Locally]
    Code --> Quality[4. Pass CI & SonarQube]
    Quality --> PR[5. Open Pull Request]
    PR --> Review[6. Review & Merge]
```
